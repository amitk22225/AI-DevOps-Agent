# Deploy checklist — prod-agents (prod)

Generated by **AgentForge**. Review every file before apply.

## Prerequisites

- AWS account **123456789012**, region **us-east-1**.
- Terraform **>= 1.5** (if using Terraform) or CDK CLI (if using CDK).
- GitHub/GitLab OIDC trust on IAM role `prod-agents-prod-deploy` (see `oidc-trust-policy.json`).
- S3 state bucket & DynamoDB lock table exist (names referenced in `main.tf` backend block) **before** first `terraform init`.

## IAM deploy role

- Role ARN: `arn:aws:iam::123456789012:role/prod-agents-prod-deploy`
- Attach policies your pipelines need (Terraform/CDK/CloudFormation execution, and DevOps Agent AWSCC resources if applicable).

## Order of operations

1. Create OIDC provider + IAM role trust (GitHub: `token.actions.githubusercontent.com`).
2. Bootstrap remote state bucket + lock table.
3. `terraform init` → `terraform plan` in `infrastructure/terraform/prod`.
4. If **AWS DevOps Agent** resources are included, ensure `awscc` provider credentials and service quotas.
5. Merge pipeline workflow files; set GitHub variable `AWS_ACCOUNT_ID` to `123456789012`.
6. Push to GitHub — open a PR to run **terraform plan** (see `GITHUB-SETUP.md`).
